# Changelog

This repository publishes two independently versioned prototypes. Versions are not semantically synchronized.

## Standalone — v0.3.1

- Four sessions of eight mono/stereo participants, forward-only inter-session routing.
- Independent A/B/C group mixes and mono/stereo hardware output assignment.
- Auto Session Sleep for sessions without available input routes.
- Callback load measurement and session ACTIVE/SLEEP status in Overview.
- Three-millisecond reactivation fade and detector reset.
- Original Classic/Smart, SharedPool, PHON and KEY DSP preserved.

## Standalone — v0.3.0

- Expanded 2-session modular routing to four sessions.
- Added inter-session routing from any earlier session and updated Overview.

## Standalone — v0.2.0 to v0.2.0b

- First modular two-session PATCH with stereo support and group outputs.
- Windows build fixes for JUCE API and test targets.

## Insert VST3 — v0.1.5

- Transferred the standalone PHON/RESPONSE UI and macro mapping.
- Preserved v0.1.4 Insert plugin identification, track-name display and existing parameter model.
- Added PHON mapping unit test.

## Insert VST3 — v0.1.4

- REAPER track names and meter stability improvements (source baseline for v0.1.5).
