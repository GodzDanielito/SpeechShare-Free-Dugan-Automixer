# Security policy

SpeechShare currently ships **experimental prototypes**, not production-certified audio infrastructure.

Do not publish sensitive vulnerabilities that could affect live audio services, network interfaces or studio routing in a public issue. Instead use GitHub's private vulnerability reporting / private security advisories for this repository when enabled by the maintainer. If that feature is disabled, ask the maintainer to enable it before sharing exploit details.

Do not attach proprietary recordings, credentials, MAC/IP topology, venue identifiers or raw configuration files containing personal data.

There is no guaranteed support window or security SLA for versions v0.3.1 (standalone) and v0.1.5 (VST3).
